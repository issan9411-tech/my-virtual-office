# Claude Code トークンダッシュボード

Claude Code のトークン消費を日次・週次・月次でモニタリングし、
**プラン変更(Pro / Max 5x / Max 20x)の判断材料**を表示するローカル Web ページです。

![構成](#) `~/.claude/projects/` のローカルログ → [ccusage](https://github.com/ryoppippi/ccusage) で集計 → このダッシュボードで可視化

## 必要なもの

- Node.js 18 以上(`node -v` で確認)
- Claude Code を使用している PC(ログ `~/.claude/projects/` がその PC に溜まります)

ccusage は初回アクセス時に `npx` 経由で自動取得されます。
毎回の起動を速くしたい場合は `npm install -g ccusage` でグローバルインストールしておくと、そちらが優先的に使われます。

## 起動方法

### Windows

`start.bat` をダブルクリック(ブラウザが自動で開きます)。

### macOS / Linux

```sh
sh token-dashboard/start.sh
```

その後 http://localhost:4545 を開いてください。
ポートを変えたい場合は環境変数 `PORT` を指定します(例: `set PORT=8080 && node server.js`)。

## スマホから見る

### 同じ Wi-Fi 内(自宅など)

`start-lan.bat` をダブルクリックして起動すると、コンソールに

```
→ http://192.168.x.x:4545?token=123456789   (同じ Wi-Fi のスマホから)
```

のような URL が表示されるので、それをスマホのブラウザで開いてください(PC が起動している間だけ見られます)。

- 初回起動時に Windows ファイアウォールの許可ダイアログが出たら「アクセスを許可」を選んでください。
- URL 末尾の `?token=...` は簡易アクセス制限です(`start-lan.bat` が毎回ランダム生成)。一度開けば Cookie に保存されるため、次回からはトークンなしで開けます。トークンを固定したい場合は起動前に環境変数 `DASH_TOKEN` を設定してください。
- macOS / Linux では `HOST=0.0.0.0 DASH_TOKEN=好きな値 sh start.sh` で同じことができます。

### 外出先から

ポート開放(グローバル公開)は推奨しません。代わりに [Tailscale](https://tailscale.com/) を PC とスマホの両方にインストールすると、自宅 PC に外からでも安全に届くプライベートな IP(100.x.x.x)が割り当てられます。あとは上記 LAN モードで起動し、スマホから `http://100.x.x.x:4545?token=...` を開くだけです(無料枠で十分です)。

## 画面の見方

| セクション | 内容 |
|---|---|
| **今月の API 換算コスト** | 同じ使い方を API 従量課金でした場合の金額。メーターの ▲ がプラン料金、薄い延長部分が月末予測(経過日数による線形換算)です。 |
| **判定** | 月末予測とプラン料金の比率から、ダウングレード/現状維持/アップグレードの目安を表示します。 |
| **現在の5時間ブロック** | Max プランのレート制限は5時間単位の枠で回復します。枠内の消費と燃焼率、リセットまでの時間を表示します。 |
| **KPI タイル** | 今日/今週(月曜起点)/今月/全期間のコストとトークン。 |
| **チャート** | API 換算コスト(モデル別)とトークン消費(種別)。期間・粒度フィルタは下のテーブルにも連動します。凡例クリックで系列の表示/非表示を切り替えられます。 |

### プラン判断の考え方

サブスクリプションの価値 = 「API 換算コスト ÷ プラン料金」で近似しています。

- **予測が $20 未満** … Pro でも収まる可能性が高い水準
- **予測がプラン料金未満(比 < 1)** … 使用量ベースでは元が取れていない
- **比 1〜3 倍** … 現在のプランで十分に元が取れている
- **比 3 倍超** … レート制限に頻繁に当たっているなら上位プラン検討の目安

比率はあくまで目安です。実際のプラン変更は「レート制限にどれくらい当たって作業が止まるか」という体感と合わせて判断してください(制限への到達回数はログに記録されないため、ここでは5時間ブロックの燃焼率を代理指標にしています)。

プラン料金の既定値は Pro $20 / Max 5x $100 / Max 20x $200 です。改定された場合は画面の「カスタム」で金額を直接指定してください。

## 計測範囲の注意

- 集計対象は **Claude Code(CLI / デスクトップ / IDE 連携)のローカルログ**のみです。
- claude.ai の Web チャットはログが取得できないため**含まれません**。
- クラウド実行(Claude Code on the Web など)の使用分はその実行環境側にログが残るため、この PC の集計には含まれません。
- コストは ccusage がモデル別 API 単価から換算した参考値で、実際の請求額ではありません。

## 構成

```
token-dashboard/
├── server.js          # 依存ゼロの Node サーバー(ccusage を子プロセスで実行)
├── public/index.html  # ダッシュボード本体(単一ファイル、外部ライブラリなし)
├── start.bat          # Windows 用起動スクリプト
├── start.sh           # macOS / Linux 用起動スクリプト
└── README.md
```

サーバーは `127.0.0.1` のみにバインドするため、LAN 上の他端末からはアクセスできません。
